# 선언형이란 무엇인가?
- 명령형과 선언형 중 후자에 대한 간단한 비유를 들어보겠습니다.
- 흔히 명령이라 함은, 지시를 뜻합니다. 예컨대 "~하여라"로 의사표시가 전달되는 형태이지요.
- 명령형 역시 마찬가지입니다. 무언가를 특정하여 지시를 하는 뜻입니다.
- 단, 선언형은 지시라기 보단 되려 '무엇'에 대한 부탁에 가깝다고도 할 수 있겠습니다. 이를테면 "~원한다."에 가깝지요.
- 요컨대, '청소를 해라'는 명령형이라면, '방이 정돈된 상태면 좋겠다'는 선언형인 셈입니다.

# 실습 과정에서 당황스러웠던 일화
- kubectl delete pod -l app=guestbook 명령어를 통하여 guestbook의 pod 삭제 시, 의외로 제거하는 데까지 시간
  소모가 됩니다. 이럴 경우에는 삭제가 될 때까지 기다려야 합니다.
- 만일 삭제가 된 것 같지 않은 탓에 괜시리 선험하여 minikube를 종료시키는 일을 저지른다면, 삭제는커녕 minikube를
  재시작하여야 하는 번거로움만 생깁니다.
